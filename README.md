# Yala

Personal finance app for iOS.

## Stack

- Swift, SwiftUI, SwiftData
- **Target iOS 26+**
- Simulator: iPhone 17 Pro

## Schemes

| Scheme | Use |
|--------|-----|
| **Yala** | Production |
| **Yala Dev** | Development (`DEV_BUILD`, Pro toggle) |
| **YalaTests** | Unit tests (Swift Testing) |
