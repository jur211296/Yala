# Redise\u00f1o Web Yala - Plan Estrat\u00e9gico

*Creado: 2026-01-25*

## Objetivo

Crear una landing page que:
1. Se diferencie visualmente de netoapp.es
2. Cuente una historia \u00fanica (no copiar Problema \u2192 Soluci\u00f3n \u2192 Resultado)
3. Tenga elementos que la competencia NO tiene
4. Transmita confianza y profesionalismo
5. No se vea "hecha por IA"

---

## An\u00e1lisis Competitivo: netoapp.es

### Lo que hacen bien
- Storytelling completo (Problema \u2192 Soluci\u00f3n \u2192 Resultado)
- Paleta c\u00e1lida (verde menta + beige)
- Marca memorable (punto verde ".")
- FAQ que reduce objeciones
- Trust indicators claros

### Lo que NO tienen (oportunidades)
- Video demo
- Testimonios reales
- Comparativa con otras apps
- M\u00e1s de 2 idiomas
- Dark mode en web
- Historia de marca/fundadores

## Identidad Visual Diferenciada

### Paleta de Colores (DIFERENTE a netoapp.es)

netoapp.es usa: Verde menta (#10B981) + Beige
Nosotros usamos: **Electric Indigo + Midnight + Accents**

```css
/* Colores principales */
--yala-primary: #6366F1;        /* Electric Indigo */
--yala-primary-light: #818CF8;
--yala-primary-dark: #4F46E5;

/* Fondos */
--yala-bg-dark: #0F0F14;        /* Midnight - casi negro con tinte azul */
--yala-bg-card: #1A1A24;        /* Cards oscuras */
--yala-bg-light: #FAFBFC;       /* Modo claro */

/* Acentos */
--yala-accent-success: #10B981; /* Verde para confirmaciones */
--yala-accent-warning: #F59E0B; /* Amarillo para alertas */
--yala-accent-error: #EF4444;   /* Rojo para errores */

/* Texto */
--yala-text-primary: #F4F4F5;
--yala-text-secondary: #A1A1AA;
--yala-text-muted: #71717A;

/* Gradientes */
--yala-gradient-hero: linear-gradient(135deg, #6366F1 0%, #8B5CF6 50%, #A855F7 100%);
--yala-gradient-cta: linear-gradient(135deg, #4F46E5 0%, #6366F1 100%);
```

### Por Qu\u00e9 Esta Paleta

| Elemento | netoapp.es | Yala | Raz\u00f3n |
|----------|------------|------|---------|
| Primario | Verde menta | Indigo el\u00e9ctrico | M\u00e1s tech/premium |
| Fondo | Beige c\u00e1lido | Midnight oscuro | M\u00e1s moderno/fintech |
| Sensaci\u00f3n | Amigable/casual | Profesional/confiable | Diferenciaci\u00f3n clara |

### Tipograf\u00eda

```css
/* Headlines */
font-family: 'Plus Jakarta Sans', system-ui, sans-serif;
font-weight: 700;
letter-spacing: -0.02em;

/* Body */
font-family: 'Inter', system-ui, sans-serif;
font-weight: 400;
line-height: 1.6;
```

### Elementos de Marca \u00danicos

1. **Punto morado "."** - Como netoapp.es tiene punto verde, nosotros punto morado/indigo
2. **Gradiente firma** - Indigo \u2192 Purple \u2192 Magenta en CTAs
3. **Ilustraciones propias** - NO iconos gen\u00e9ricos de Lucide/Heroicons
4. **Animaciones fluidas** - Micro-interacciones en hover/scroll

## Elementos Anti-IA (Para No Verse Gen\u00e9rico)

1. **Ilustraciones personalizadas** en lugar de iconos de librer\u00eda
2. **Fotograf\u00eda real** del equipo (si es posible)
3. **Copywriting con personalidad** - frases coloquiales peruanas/latinas
4. **Bento grid asim\u00e9trico** en lugar de grid uniforme
5. **Video real** en lugar de mockups est\u00e1ticos
6. **Historia de origen** que humaniza la marca
7. **Micro-copy con humor sutil** ("Spoiler: no vendemos tus datos")
