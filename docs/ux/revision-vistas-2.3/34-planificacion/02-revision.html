Lo que más se repite: P2 (principiante) y P7 (texto grande) se traban por la misma causa: el estado de un presupuesto o de un pago se dice con color y piezas pequeñas, y las acciones viven un nivel más abajo (detalle, menú de cada fecha). Lo que ya está bien

  • «Ya lo pagué» apunta el pago en un toque desde la hoja, con el importe editable (L10-9).
  • Saltar deja «Deshacer» y nombra la fecha («Saltaste el pago del 20 de noviembre»).
  • Con el mes pagado, los botones nombran el siguiente («Ya pagué diciembre», «Saltar diciembre»).
  • Borrar un presupuesto nombra cuál y tranquiliza: «Tus gastos no se borran: solo este límite» (L9-14).
  • El editor de pagos marca «Falta» en cada campo y resume el plan en una frase («S/ 18.00 cada mes, el día 18»).
  • «Cuenta todos tus gastos» avisa cuando un presupuesto no tiene categorías (L9-2).
  • Gráficas: barras neutras y rosa solo para los meses que se pasaron (L9-7).
