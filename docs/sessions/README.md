# Sesiones

Working: docs de **una** sesión o de un corte concreto.

Nombre: `YYYY-MM-DD-slug.md` (kebab-case inglés o español, slug corto).

No es SSOT de tickets (eso es `tickets/`) ni de decisiones (`docs/DECISIONS.md`).

Al cerrar la sesión o quedar stale: `git mv` a `_archive/`. No se borra.

No inventar PASS ni estado de build.
