# Lenguaje de Marca - Yala

*Documentado: 2026-01-26*

Este documento define el tono, estilo y mensajes de Yala. Es **obligatorio** consultarlo antes de escribir cualquier texto visible al usuario (UI, notificaciones, emails, web, redes sociales).

---

## 1. Principios Fundamentales

### 1.1 Personalidad de Marca
Yala es como **un amigo que sabe de finanzas**: cercano, confiable, práctico y jovial.

| Adjetivo | Significado |
|----------|-------------|
| **Empática** | Entiende la ansiedad financiera y la reduce |
| **Práctica** | Soluciones concretas, no teoría |
| **Confiable** | Profesional sin ser fría |
| **Jovial** | Positiva sin ser infantil |

### 1.2 El Tono en Una Frase
> "Un amigo financiero que te dice las cosas simples, te anima cuando lo haces bien, y te da un empujoncito cuando lo necesitas."

---

## 2. Directrices de Tono

### 2.1 Cercano y Conversacional

**Usar:** Segunda persona ("tú") de manera amigable, como un amigo experto.

| NO escribir | SÍ escribir |
|-------------|-------------|
| "Bienvenido al sistema de gestión financiera Yala. Proceda a registrar sus transacciones" | "¡Hola! Empecemos a organizar tu dinero. ¿Cuál fue tu último gasto?" |
| "El usuario debe ingresar el monto" | "Ingresa el monto" |
| "Se ha completado el registro" | "¡Listo! Tu gasto quedó registrado" |

**Frases motivacionales permitidas:**
- "¡Tú puedes con tus finanzas, Yala está para ayudarte!"
- "Vas muy bien, sigue así"
- "Un paso más hacia tus metas"

### 2.2 Profesional y Claro

Mantener equilibrio: cercano pero con credibilidad financiera.

**Términos preferidos:**

| Evitar | Usar |
|--------|------|
| "Balance" | "Saldo" |
| "Cashflow" | "Flujo de caja" |
| "Budgeting" | "Presupuestar" / "Armar un presupuesto" |
| "Income/Expense ratio" | "Relación ingreso-gasto" |
| "Default" | "Por defecto" / "Predeterminado" |

**Conceptos técnicos:** Si se mencionan (OCR, IA), acompañar con explicación breve la primera vez.
- "Escaneo OCR (lectura automática de texto)"
- "Nuestra IA (inteligencia artificial) aprende tus patrones"

### 2.3 Neutro Regionalmente

Español estándar entendible en cualquier país hispanohablante.

**Palabras universales:**

| Local/Coloquial | Universal |
|-----------------|-----------|
| "Plata" (informal) | "Dinero" |
| "Lucas" (Chile) | "Dinero" |
| "Lana" (México) | "Dinero" |
| "Chibolo" (Perú) | "Joven" |
| "Billetera" / "Cartera" | Ambas aceptables |

**Ejemplos neutrales permitidos:**
- "Un cafecito cada día" (gasto hormiga - universal)
- "Comer fuera" (universal)
- "Delivery" / "Pedidos a domicilio" (ambos entendibles)

**Evitar en copy principal:**
- Referencias muy locales (Inka Kola, anticuchos, tacos específicos)
- Modismos regionales ("pucha", "órale", "vale tío")
- Estos se pueden usar en marketing segmentado para redes sociales locales

### 2.4 Inspirador y Orientado a Solución

**Nunca regañar.** Proponer alternativas y celebrar logros.

| Tono negativo (NO) | Tono constructivo (SÍ) |
|--------------------|------------------------|
| "Estás gastando demasiado en restaurantes este mes" | "Has alcanzado el 90% de tu presupuesto en restaurantes. ¿Qué tal si cocinamos en casa estos días?" |
| "Te excediste del presupuesto" | "Ups, pasaste tu presupuesto. Mañana es otro día para volver a intentar, ¡ánimo!" |
| "No has registrado gastos en 5 días" | "¡Te extrañamos! ¿Qué tal si ponemos al día tus gastos?" |
| "Error: categoría no válida" | "Hmm, esa categoría no existe. ¿Quieres crear una nueva?" |

**Celebrar logros:**
- "¡Felicidades! Alcanzaste tu meta de ahorro este mes"
- "¡Genial! Llevas 7 días registrando gastos"
- "¡Vas por buen camino, tus finanzas están 'yala'!"

## 3. Uso de Emojis

### 3.1 Reglas Generales
- **Moderado:** 1-2 emojis máximo por mensaje
- **Contextuales:** Deben aportar significado, no decorar
- **Positivos:** Reforzar emociones positivas

### 3.2 Emojis Aprobados por Contexto

| Contexto | Emojis permitidos |
|----------|-------------------|
| Logros/Celebraciones | 🎉 ✨ 🏆 ⭐ |
| Tips/Consejos | 💡 📝 |
| Alertas suaves | ⚠️ 👀 |
| Dinero/Finanzas | 💰 💵 📊 |
| Comida (ejemplos) | 🍕 ☕ 🥘 |
| Ánimo | 💪 🙌 👏 |
| Tiempo | ⏰ 📅 |

### 3.3 Ejemplos de Uso

```
✅ "💡 Tip Yala: revisa tus gastos hormiga de esta semana"
✅ "🎉 ¡Meta alcanzada! Ahorraste S/ 500 este mes"
✅ "☕ Tu café diario suma S/ 150 al mes"

❌ "💰💰💰 ¡Mucho dinero gastado! 😱😱😱" (exceso)
❌ "Error en el sistema 🤖⚙️🔧" (no aporta)
```

## 4. Mensajes por Tipo

### 4.1 Onboarding
```
Bienvenida: "¡Hola! Soy Yala, tu compañera de finanzas. Vamos a organizar tu dinero juntos."
Primer paso: "Empecemos creando tu primera cuenta. ¿Dónde guardas tu dinero principal?"
Completado: "¡Perfecto! Ya tienes todo listo para empezar. ¿Registramos tu primer gasto?"
```

### 4.2 Notificaciones

**Push notifications:**
```
Recordatorio: "👋 ¿Cómo van tus gastos hoy?"
Logro: "🎉 ¡Completaste tu primera semana registrando gastos!"
Alerta presupuesto: "💡 Llevas el 80% de tu presupuesto en Comida"
```

**In-app:**
```
Presupuesto excedido: "Has superado tu presupuesto de [categoría]. No pasa nada, ajustemos para el próximo mes."
Meta alcanzada: "¡Lo lograste! Cumpliste tu meta de ahorro. ¿Creamos una nueva?"
```

### 4.3 Estados Vacíos

```
Sin transacciones: "Aquí aparecerán tus gastos. ¡Registra el primero!"
Sin categorías: "Crea categorías para organizar mejor tus gastos"
Sin presupuestos: "Los presupuestos te ayudan a no gastar de más. ¿Creamos uno?"
```

### 4.4 Errores

```
Error de red: "Sin conexión. Tus datos están guardados, se sincronizarán cuando vuelvas a conectarte."
Error de validación: "Hmm, algo no está bien. Revisa que el monto sea correcto."
Error inesperado: "Algo salió mal. Intenta de nuevo en un momento."
```

### 4.5 Confirmaciones

```
Gasto registrado: "✓ Gasto registrado"
Eliminación: "¿Seguro que quieres eliminar este gasto? Esta acción no se puede deshacer."
Cambios guardados: "Cambios guardados"
```

## 5. Inclusividad

### 5.1 Género
- Preferir hablar directamente con "tú" (evita marcar género)
- Usar plurales genéricos cuando aplique
- Evitar "estimado usuario" → "Hola" o simplemente el nombre si lo tenemos

### 5.2 Diversidad
- No asumir estructura familiar específica
- No asumir que solo hombres manejan finanzas
- Ejemplos variados en tutoriales y tips

### 5.3 Accesibilidad
- Textos claros y concisos
- Evitar solo color para comunicar significado
- Labels descriptivos en botones

## 8. Frases Prohibidas

| Nunca decir | Por qué |
|-------------|---------|
| "Debes..." / "Tienes que..." | Suena a obligación |
| "Es fácil" / "Es simple" | Puede frustrar si no lo es para el usuario |
| "Obviamente..." | Condescendiente |
| "Como ya sabes..." | Asume conocimiento |
| "Error crítico" / "Fallo grave" | Genera ansiedad innecesaria |
| "Estimado usuario" | Frío y corporativo |
| "Transacción" (excepto contextos técnicos) | Usar "gasto" o "ingreso" |

## 9. Adaptación Internacional

### 9.1 Base Actual
- Español neutro latinoamericano
- Enfoque inicial: Perú y LATAM

### 9.2 Futuras Localizaciones
Cuando se expanda a nuevos mercados:
- Mantener el núcleo del tono
- Adaptar modismos locales (cartera/billetera, carro/auto)
- Crear versiones localizadas de marketing

### 9.4 Variante es-AR (excepción gramatical)

A partir del épico de localización (commits `5fc6d9c4` y siguientes), Yala soporta la variante `es-AR` con voseo argentino. **Es la única variante país que rompe la regla de "neutralidad regional"** y se justifica únicamente por su naturaleza gramatical:

- **Sí incluye:** voseo verbal (vos tenés/podés/sabés/sos/hacés/decís), pronombre "vos" donde aparece "tú" explícito.
- **NO incluye:** modismos coloquiales (guita, boludo, che, dale como saludo). Estos siguen prohibidos por §2.3.

**Criterio para futuras variantes país:** solo si la diferencia es gramatical/estructural (no léxica). Por ejemplo, `es-MX` con "carro" en lugar de "auto" NO justifica una variante — el cambio es léxico y el LatAm neutro lo cubre. Pero si en el futuro quisiéramos soportar tuteo formal de Centroamérica con conjugación distinta, sí podría justificarse.

### 9.3 Inglés (Futuro)
- Mantener el "you" amigable
- Evitar voz pasiva
- Conservar el tono cercano y directo

## 10. Checklist para Nuevo Copy

Antes de publicar cualquier texto, verificar:

- [ ] ¿Usa "tú" y es conversacional?
- [ ] ¿Es entendible en cualquier país hispanohablante?
- [ ] ¿Evita jerga técnica o la explica?
- [ ] ¿El tono es positivo y constructivo?
- [ ] ¿Los emojis son moderados y aportan?
- [ ] ¿Es inclusivo en género?
- [ ] ¿Suena a Yala, no a un banco?
