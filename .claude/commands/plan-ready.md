description: Extrae plan y prepara para compactar (termina con Shift+C)
---

Extrae el plan de la sesión de planificación y lo presenta de forma compacta.
**Al final, el usuario debe presionar Shift+C para compactar.**

## CUÁNDO USAR

```
Shift+Tab → [planificación] → [Esc] → /review-plan → /plan-ready → Shift+C → /session-start
```

## EJECUCIÓN

### PASO 1: Extraer el plan final

Identificar:
- Objetivo de la tarea
- Lista de pasos/incrementos del plan
- Archivos clave a modificar
- Decisiones importantes tomadas

### PASO 2: Presentar resumen ULTRA-COMPACTO

Mostrar SOLO esto (sin explicaciones adicionales):

```
═══════════════════════════════════════════════════════════════
                      PLAN EXTRAÍDO
═══════════════════════════════════════════════════════════════

OBJETIVO: [una línea]

PASOS:
1. [paso 1]
2. [paso 2]
3. [paso 3]

ARCHIVOS:
• [archivo 1]
• [archivo 2]

DECISIONES:
• [decisión 1]
• [decisión 2]

═══════════════════════════════════════════════════════════════
              PRESIONA Shift+C PARA COMPACTAR
═══════════════════════════════════════════════════════════════
Después: /session-start o /yolo
```

### REGLAS

- NO agregar explicaciones largas
- NO preguntar si quiere ver más detalles
- SÍ ser lo más conciso posible
- El plan arriba ES el contexto que sobrevivirá al compact

## RESULTADO

1. Usuario ve el plan extraído
2. Usuario presiona Shift+C (compacta preservando el plan visible)
3. Usuario ejecuta `/session-start` o `/yolo`
